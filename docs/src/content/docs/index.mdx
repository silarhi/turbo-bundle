import { Card, CardGrid } from '@astrojs/starlight/components'

```bash
composer require silarhi/turbo-bundle # PHP half
pnpm add @silarhi/turbo               # JS half
```

The two halves solve different problems and only meet on [redirect following](/php/frame-redirects/): the server
turns a frame redirect into a `Turbo-Location` header, the browser handler follows it.

<CardGrid>
    <Card title="One lifecycle hook pair" icon="rocket">
        `onMount` / `onUnmount` run on Drive renders, frame loads and Stream mutations alike.
        [TurboHandler](/javascript/turbo-handler/)
    </Card>
    <Card title="Morph-aware" icon="random">
        Stream renders are diffed per node (mount wins, never a double mount); Drive and Frame morphs can opt into
        per-element refresh. [Morph mutations](/javascript/morph-mutations/)
    </Card>
    <Card title="Frame-redirect following" icon="right-arrow">
        A redirect inside a Turbo Frame becomes a full Drive visit instead of a frame swap, `DELETE` redirects too.
        [Frame redirects](/php/frame-redirects/)
    </Card>
    <Card title="turbo_frame Twig filter" icon="document">
        Extend a lean frame template only when the request targets a matching frame. [The
        filter](/php/turbo-frame-filter/)
    </Card>
    <Card title="Framework-optional" icon="puzzle">
        The bundle wires everything with zero configuration; the classes also work with Symfony components alone.
        [Without the framework](/php/without-framework/)
    </Card>
</CardGrid>
